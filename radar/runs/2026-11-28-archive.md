# Radar run: archive 2026-11-28

- Daypart: Archive (even date, 00:00 Europe/Bucharest on 2026-11-28; fired 23:53 EET on 2026-11-27 = 16:53 EST), per `radar/dayparts.yaml` (keep_rate 0.2 hard cap, pre-2018 preferred, clusters archive/language/engine/craft, source_bias acm-sigplan-dblp / acm-siggraph-tog / eurographics-cgf / acl-anthology / arxiv / hpg-jcgt)

- Branch: `radar/archive-2026-11-28`
- Method: **table-of-contents sweep**, the hand-off from the 11-24 and 11-26 runs. dblp's TOC pages and search API now sit behind an Anubis "Making sure you're not a bot" wall for the box, so the TOCs came from the publishers' DOI metadata instead. Crossref journal listings by ISSN gave ACM TODS 1976–1990, CACM 1974–1985, Computer Graphics (SIGGRAPH proceedings) 1980–1992, APL Quote Quad (APL conferences) 1979–1995 and SIGPLAN Notices 1979–1995 (which carries PLDI/POPL/PPoPP-era proceedings). DataCite (prefix 10.20380) gave Graphics Interface 1982–1995. Every title was deduped by normalized title prefix and DOI against `seeds/cards/`, `summaries/`, every run log and `seen.json`. A keyword cheap filter, then a hand skim of the surviving titles, gave the shortlist. Each shortlisted name got a second targeted probe (~110 probes) over the same corpus.
- Full texts: all three keepers read in full (Batory and Buneman & Clemons from Internet Archive snapshots of the ACM PDFs, because dl.acm.org returns 403 to the box; Paeth from the Internet Archive copy of the GI proceedings PDF). Girardot's A+ paper was also read in full and not kept. DOIs checked with doi.org redirects and Crossref.

## Near misses

See `archive_2026_11_28_near_keepers` in `radar/seen.json` (7):

- **Shipman 1981 DAPLEX** (TODS): third deferral. No Internet Archive snapshot of the PDF or ePDF exists (only the landing page), the web fetcher timed out on both ACM URLs, headless Chrome returned nothing, and dl.acm.org gives 403. Still the best ano fit not yet carded.
- **Fordyce & Sullivan 1987, Boolean array structures for a rule-based forward chaining inference engine** (APL 87): the most direct OPS5 × APL crossover in the sweep. An Internet Archive PDF snapshot exists, but two downloads timed out, so it is unread. First pick for next Archive.
- **Gharachorloo, Gupta, Sproull & Sutherland 1989, A characterization of ten rasterization techniques** (SIGGRAPH): PDF in hand, deferred for the keep rate.
- **Whang, Vander-Zanden & Taylor 1990, linear counting** (TODS) and **Valduriez 1987, join indices** (TODS): both reachable and both column-store companions to 2739.
- **Kajiya & Ullner 1981, Filtering high quality text for display on raster scan devices** (SIGGRAPH): scanline text, but only the landing page is archived.
- **Girardot 1990, The A+ programming language, a different APL** (APL90): read in full, and it is *not* Whitney's Morgan Stanley A+. It is an École des Mines APL dialect with lexical binding, brace blocks whose arguments are implicitly named `a` and `w`, blocks as first-class scalar closures, and a stack VM written in APL. An interesting dfns precursor, but it would mislead anyone looking for the kdb+ line.
