## Keepers
- 2417 The Goose Programming Language — Wouter van Oortmerssen (v2026.1–v2026.3, 14–21 Oct): a memory-safe language with no heap, GC or RC. The compiler assigns data to bump-pointer stacks, links are relative 1/2/4-byte offsets so data doubles as its file format, ADTs are variable-mode, and workers share nothing. Geomean over 16 benchmarks: 1.13× faster than safe Rust and 1.24× faster than hand-optimized C++ (MSVC) (languages, 9).
- 2418 bbtree: fastest ordered map — Xiangpeng Hao (Oct): inline key prefixes, SIMD popcount search, batched lookups as async prefetch state machines, version-locked inner nodes, free list instead of epochs, Verus proofs, Shuttle/ffs deterministic simulation tests. Reported 5× faster than std `BTreeMap`, 12× faster than crossbeam-skiplist at 96 threads, and 1.37–6.83× faster in LSM-tree memtables (systems, 9).
- 2419 Virtual Shadow Maps (GPU Zen 3 chapter, Markdown edition) — Sakmary et al. (graphics-programming.org, 12 Oct): fully GPU-driven 16-cascade clipmap VSM with page caching, a sliding-window page table, a two-buffer GPU allocator and hierarchical-page-buffer meshlet culling in task shaders. Vulkan code is in Timberdoodle (graphics, 8).
- 2420 How close can pure FP get to C? — Richard Feldman (22 Oct): roc-deflate runs a median 8.9% (x64) and 2.6% (M1) slower than libdeflate. Techniques: keep values unique for in-place mutation, hoist bounds checks, build tables at compile time, use wrapping arithmetic (languages, 7).
