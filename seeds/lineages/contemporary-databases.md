# contemporary-databases

**Charter.** Modern database and data-systems classics spanning globally distributed SQL/KV (Spanner, Cockroach, FoundationDB, Aurora), cloud warehouses & lakehouses (Snowflake, BigQuery/Dremel, Iceberg, Delta, Photon), embeddable/vectorized analytics (DuckDB, DataFusion, Velox, Umbra/HyPer), storage engines (LSM/RocksDB), learned indexes/optimization, and streaming incremental engines (Differential Dataflow, Materialize, Flink). Prefer this lineage for post-2010 data stack threads; cite `algorithms-and-complexity` for classical consensus/coding roots.

## Ordered spine

1. **Distributed SQL / KV** — Spanner, F1, CockroachDB, FoundationDB, Aurora, Dynamo/Bigtable roots
2. **Cloud warehouses & lakehouses** — Snowflake, Dremel/BigQuery, Iceberg, Delta, Presto, Spark
3. **Execution & storage** — HyPer/Umbra, Calcite, vectorized/compiled queries, RocksDB/LSM, Arrow/DataFusion/Velox/DuckDB
4. **Learned components & streaming** — learned indexes, Differential Dataflow / Materialize, Flink
