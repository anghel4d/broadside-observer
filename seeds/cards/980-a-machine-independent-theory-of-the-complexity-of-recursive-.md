# A Machine-Independent Theory of the Complexity of Recursive Functions

## One-sentence takeaway

Blum axioms give machine-independent complexity measures and imply speedup phenomena.

## Why it matters here

Abstract complexity backbone behind later structural complexity.

## Key ideas

- Axiomatic complexity measures.
- Blum speedup theorem.
- Machine-independence via axioms.
- Separates measure theory from particular models.

## Caveats

- Very abstract — not a cookbook for algorithm design.
- Concrete class separations need more structure.
