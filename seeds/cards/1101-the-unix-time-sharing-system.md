# The UNIX Time-Sharing System

## One-sentence takeaway

UNIX as a small, elegant time-sharing OS: hierarchical file system, processes, pipes, and the tool composition culture.

## Why it matters here

The OS aesthetic Broadside/ano still live inside—files, processes, and composable filters.

## Key ideas

- Hierarchical file system as universal namespace.
- fork/exec process model.
- Pipes and tool composition.
- Simplicity as a systems-design weapon.

## Caveats

- Classic; verify claims against the primary text before engineering decisions.
