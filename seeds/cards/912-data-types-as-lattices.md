# Data Types as Lattices

## One-sentence takeaway

Develops the lattice/domain model in which recursive data types and lambda models live.

## Why it matters here

Classic Scott domain-theory paper for modeling untyped/typed computation and recursive types.

## Key ideas

- Complete lattices / continuous lattices as data types.
- Solves recursive domain equations for lambda models.
- Mathematical substrate for denotational semantics.
- Companion to Domains for Denotational Semantics.
