# Report on the Programming Language Haskell: A Non-strict, Purely Functional Language

## One-sentence takeaway

The Haskell 1.2/early report defining a non-strict, purely functional language with type classes.

## Why it matters here

Haskell's founding report — lazy + pure + type classes as a community language design.

## Key ideas

- Non-strict pure functional programming as default.
- Type classes for ad-hoc polymorphism.
- Community language design process.
- Pairs with Wadler–Blott and Peyton Jones implementation book.
