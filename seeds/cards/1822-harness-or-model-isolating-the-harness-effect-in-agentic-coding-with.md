# Harness or Model? Isolating the Harness Effect in Agentic Coding with a Contamination-Controlled Private Suite

## One-sentence takeaway

Paired same-model contrasts on a private contamination-controlled suite show the coding-agent harness — not just the base LLM — moves a large share of solve rate.

## Why it matters here

Broadside’s standing model-vs-harness cut (1050 / 1536 / 1573 / 1768 / 1798) finally gets a clean measurement protocol: same model, swapped harness, private post-cutoff tasks. Anoptic tool buses and GRID COMMAND order harnesses should copy the paired-contrast discipline before claiming “model upgrade” wins.

## Key ideas

- Defines the agentic coding system as model + harness (tools, prompts, control flow) and measures the harness effect in isolation.
- Runs paired same-model contrasts on a private suite of 256 repository and post-cutoff contest tasks — contamination-controlled.
- Shows vendor-native harness pairings are not automatically best; harness choice moves solve rate under a fixed LLM.
- Gives Broadside a template for attributing failures to harness vs weights instead of blending them in leaderboard deltas.

## Caveats

Private suite limits external replication; abstract does not publish the full harness inventory. Do not remint Ecdysis 1798, Harness Engineering 1536, or DeepSeek Harness 1050 — this is the measurement companion, not another harness trainer.
