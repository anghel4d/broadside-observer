# An Introduction to Database Systems

## One-sentence takeaway

Date's textbook taught generations the relational model as engineering practice—integrity, algebra, and SQL discipline around Codd.

## Why it matters here

Pairs with Broadside's Codd card (048): the pedagogical carrier for relational thinking that ECS/query layers still echo.

## Key ideas

- Relational algebra/calculus as the right API for shared data.
- Integrity constraints and keys as first-class design.
- Clear separation of logical vs physical database design.
- Multi-edition teaching standard spanning System R to SQL.

- Textbook card—cite a specific edition when quoting page-level claims.
