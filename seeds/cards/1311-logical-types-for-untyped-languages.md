# Logical Types for Untyped Languages

## One-sentence takeaway

Occurrence typing refines types from proposition-producing predicates in control flow.

## Why it matters here

Explains Typed Racket and TypeScript control-flow narrowing without full dependent types.

## Key ideas

- Propositions as branch refinements.
- Latent propositions on functions.
- Sound narrowing for idiomatic dynamic code.
