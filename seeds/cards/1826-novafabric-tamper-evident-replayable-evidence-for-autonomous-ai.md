# NovaFabric: Tamper-Evident, Replayable Evidence for Autonomous AI Agent Runs

## One-sentence takeaway

NovaFabric turns autonomous agent runs into tamper-evident, replayable, secret-scrubbed execution evidence that an independent party can check — traces alone are not enough.

## Why it matters here

Broadside’s provenance-first memory stance needs audit-grade run evidence, not mutable observability blobs. NovaFabric is the compliance-shaped cut (EU AI Act / ISO 42001 / NIST AI RMF) for agent trajectories that Anoptic and GRID COMMAND will eventually have to store and replay.

## Key ideas

- Argues agent-observability traces are mutable, non-replayable, and silent on secret scrubbing.
- Produces provider-neutral audit-grade execution evidence for autonomous AI agent runs.
- Targets independent verifiability — evidence another party can check, not just an operator dashboard.
- Connects regulatory record-keeping requirements to concrete agent-runtime instrumentation.

## Caveats

Primary cs.CR; engineering depth and overhead vs OpenTelemetry-style traces need a full read. Single-author abstract — verify implementation claims. Complements provenance memory cards; does not replace them.
