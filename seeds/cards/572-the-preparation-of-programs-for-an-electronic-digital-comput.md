# The Preparation of Programs for an Electronic Digital Computer

## One-sentence takeaway

Wilkes, Wheeler, and Gill document EDSAC programming and a closed subroutine library — software as a reusable, call-and-return artifact.

## Why it matters here

This is the first true programming book. Every Broadside library, plugin, and agent tool catalog inherits the closed-subroutine discipline it taught.

## Key ideas

- The EDSAC order code and initial orders (the bootstrap) are specified in enough detail to write real programs.
- Closed subroutines restore the caller; open subroutines are expanded in line. The library is organized around the former.
- Wheeler's calling sequence and the "wheel" of library tapes make relocation and linking a practiced craft.
- Numerical examples (quadrature, differential equations, tables) show a working mathematical service, not a toy.
- Addison-Wesley 1951; the 1982 Tomash/CBI reprint is the standard historical reissue.
