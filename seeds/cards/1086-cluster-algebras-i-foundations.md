# Cluster algebras I: Foundations

## One-sentence takeaway

A cluster algebra is a commutative ring generated by overlapping clusters whose binomial exchange relations \(xx'=M_1+M_2\) propagate along an \(n\)-regular tree, and every cluster variable is a Laurent polynomial in any initial cluster — the Laurent phenomenon.

## Why it matters here

Why you might love this: subtraction-free binomial recurrences that *should* explode into rational functions keep cancelling, leaving a single monomial in the denominator. The exchange graph of a rank-2 finite type is a polygon whose length is a Coxeter number plus two (a pentagon for \(A_2\), which *is* \(\mathrm{Gr}(2,5)\)). Matrix mutation of a skew-symmetrizable exchange matrix is an involution that later classifies finite type as Cartan–Killing. Bridge: mutation is a discrete integrable move on a seed — the same flavour as variational integrators and as the exchange of a cluster of gameplay parameters without leaving a Laurent chart.

## Key ideas

- Start from the \(n\)-regular tree \(\mathbb{T}_n\); each vertex carries a cluster of \(n\) variables and an exchange pattern of monomials satisfying four axioms (no self-factors, complementary supports, reciprocity, and a substitution propagation rule).
- The exponents assemble into a sign-skew-symmetric matrix \(B(t)\) mutating by \(\mu_k\); skew-symmetrizable \(B\) is the workhorse class and stays skew-symmetrizable.
- Laurent phenomenon (Thm 3.1, and the more general caterpillar-tree Thm 3.2): any cluster variable is a Laurent polynomial in any other cluster, with coefficients in the group ring of the coefficient group.
- Geometric type uses the tropical semifield, so coefficients themselves mutate by the same rule; the Grassmannian \(\mathrm{Gr}(2,n+3)\) is the prototypical example (clusters = triangulations of an \((n+3)\)-gon).

## Caveats

- This is the *foundations* paper: finite-type classification, positivity of Laurent coefficients, and the full Cartan–Killing coincidence live in the sequels — mint I, cite II.
- Exchange patterns have a large coefficient moduli space unless normalised; most geometric examples are of geometric type and are rigid given \(2n\) initial monomials.
- Not a string-diagram / cluster-category paper; those are later representation-theoretic avatars.
