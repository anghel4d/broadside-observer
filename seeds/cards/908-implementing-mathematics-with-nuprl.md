# Implementing Mathematics with Nuprl

## One-sentence takeaway

Documents the Nuprl proof development system implementing computational type theory.

## Why it matters here

Classic implemented descendant of Martin-Löf type theory — the US twin to early Coq/CoC culture.

## Key ideas

- Computational type theory as an implemented logic.
- Proof refinement and program extraction.
- Large collaborative monograph from the PRL group.
- Shows type theory scaling beyond toy examples.
