# EdgeQL Type System and Query Language

## One-sentence takeaway

EdgeQL is a typed query language over a graph-relational model with path typing.

## Why it matters here

Modern query language treating types as central rather than bolted onto SQL.

## Key ideas

- Path-aware types.
- Algebraic query shapes.
- Schema as type source.
