# A Theory of Type Polymorphism in Programming

## One-sentence takeaway

Defines the polymorphic type discipline for ML and proves soundness of the underlying type system.

## Why it matters here

Canonical Milner polymorphism paper — the type story behind SML and every HM-family language Anoptic touches.

## Key ideas

- Let-polymorphism as the practical sweet spot for functional languages.
- Semantic soundness via a model of types.
- Foundation for Algorithm W / Damas–Milner inference.
- Direct ancestor of the Definition of Standard ML.
