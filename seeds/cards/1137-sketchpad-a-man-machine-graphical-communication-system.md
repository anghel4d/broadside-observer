# Sketchpad: A Man-Machine Graphical Communication System

## One-sentence takeaway

Sketchpad invents interactive computer graphics: constraint-based drawing, instancing, and the light-pen UI.

## Why it matters here

The big-bang interactive graphics card—everything CAD/engine UI answers to Sutherland.

## Key ideas

- Interactive creation/manipulation of line drawings.
- Constraints and master/instance structure.
- Display file / recursive data structures for graphics.
- HCI + graphics born together.
