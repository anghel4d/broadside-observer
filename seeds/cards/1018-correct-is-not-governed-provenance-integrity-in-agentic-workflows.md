# Correct Is Not Governed: Provenance Integrity in Agentic Workflows

## One-sentence takeaway

A correct agent action can still be ungoverned: Matrix records which authority/facts admitted a decision, which receipts closed a task, and which dependents a later change invalidates — and a faithful completeness contract still failed to transfer (specificity 0.00).

## Why it matters here

Provenance-first agent memory is first-class on the radar. GRID COMMAND orders, standing rules, and Broadside seed cards all need “what governed this, what proved done, what went stale.” Matrix is a deterministic causal-state layer *around* the LLM, not another RAG. The negative result is the crème: mechanism fidelity ≠ contract validity — the warning we need before encoding Anoptic production rules as hard gates.

## Key ideas

- Three provenance surfaces: decision (governing vs merely retrieved), execution (receipt vs self-claim), change (dependency-scoped invalidation).
- Same-outcome splits: direct RAG 15/15 expected actions but 6/15 unsupported citations; self-review still self-closes on missing DPA evidence 3/3; authority v2 reissues 3 tasks vs 18 for full rerun.
- Metadata-decidable missing-authority invariant: Phi never self-escalates; Matrix escalates 12/12 incomplete and 0/120 complete authored packets.
- Study 6 transfer: role-separated synthetic packets, sensitivity 1.00, specificity 0.00. The paper treats this as a gate, not a footnote.

## Caveats

- Small authored fixtures, local Phi-4, seeds as stability not new tasks. No enterprise prevalence or human-load numbers.
- Not a general accuracy enhancer; not superiority over citation-verifying RAG.
- Next claim-bearing study must be independently authored. Author is Microsoft-employed; work is independent.
