# An Axiomatic Basis for Computer Programming

## One-sentence takeaway

Introduces Hoare triples {P}S{Q} as an axiomatic basis for proving program correctness.

## Why it matters here

Hoare logic root — still the verification vocabulary beside separation logic already in corpus.

## Key ideas

- Hoare triples and axioms/rules for assignment, sequencing, conditionals, loops.
- Partial correctness reasoning.
- Foundation for program verification tools.
- Companion to Floyd 1967 and Dijkstra GCL.
