# A Theory of Type Polymorphism in Programming

## One-sentence takeaway

Milner gives polymorphic type inference for ML—practical Hindley–Milner for programmers.

## Why it matters here

Makes principal types a language feature; ancestor of every modern inferred FP language.

## Key ideas

- Let-polymorphism.
- Type inference algorithm (algorithm W lineage).
- ML as carrier.

## Caveats

- Classic; read primary text before overclaiming modern interpretations.
