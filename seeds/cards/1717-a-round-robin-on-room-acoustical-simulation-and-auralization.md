# A round robin on room acoustical simulation and auralization

## One-sentence takeaway

BRAS round robin: same rooms, many simulators (GA and wave), plus auralization listening — the 2019 JASA reality check that tools disagree.

## Why it matters here

Anoptic will pick a method and overtrust it. Brinkmann/Aspöck/Vorländer/Weinzierl 2019 run a round robin on room simulation *and* auralization. Use it as the validation card: compare your tracer/FDTD to BRAS, don't invent a private test booth.

## Key ideas

- **Round robin.** Multiple labs/tools on shared scenes.
- **Simulation + listening.** Not only T30 plots — auralization quality.
- **JASA 2019.** Harvest 113 cites; geometric and wave tagged.
- **Benchmark culture.** Pair with Vorländer 2013 uncertainties (1745).

## Caveats

Scene set is architectural, not a game level with destruction. Doesn't pick a winner algorithm for GRID COMMAND. 2019 tool versions.
