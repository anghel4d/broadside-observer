# Introduction and Overview of the Multics System

## One-sentence takeaway

Multics sets the ambitious shared time-sharing agenda: hierarchical FS, dynamic linking, and security as design—not afterthought.

## Why it matters here

UNIX's foil and parent: many Broadside OS instincts (protection rings, virtual memory ambitions) pass through Multics.

## Key ideas

- Segmented virtual memory and hierarchical file system.
- Dynamic linking of procedures.
- Multi-user protection and sharing as first-class goals.
- Project MAC / Bell / GE collaboration.

## Caveats

- Overview paper—pair with later Multics implementation papers for detail.
