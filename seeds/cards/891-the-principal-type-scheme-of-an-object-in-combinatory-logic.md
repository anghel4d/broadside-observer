# The Principal Type-Scheme of an Object in Combinatory Logic

## One-sentence takeaway

Proves principal type-schemes exist in combinatory logic — the Hindley half of Hindley–Milner inference.

## Why it matters here

Root of decidable principal-type inference that ML, Haskell, and ano-style typed DSLs still rest on.

## Key ideas

- Principal (most general) type-schemes for combinatory terms.
- Algorithmic ancestry of modern unification-based inference.
- Prefigures Milner's polymorphic type discipline for programming.
- Separates type assignment from typed lambda-calculus presentations.
