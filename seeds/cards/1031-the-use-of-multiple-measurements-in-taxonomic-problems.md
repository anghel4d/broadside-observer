# The Use of Multiple Measurements in Taxonomic Problems

## One-sentence takeaway

Fisher linear discriminant — supervised projection maximizing class separation.

## Why it matters here

Canonical baseline classifier/projection before heavy ML stacks.

## Key ideas

- Between vs within class scatter.
- Linear decision boundaries.
- Iris dataset illustration historically.
- Ties to Gaussian class models.

## Caveats

- Use the method, not the era framing.
- Assumes roughly equal covariances for classic LDA.
