# Session Types for Deadlock-Free Communication

## One-sentence takeaway

Session types structure communication protocols in the type system to prevent protocol errors and often deadlocks.

## Why it matters here

Bridge from π-calculus theory to typed concurrent programming practice.

## Key ideas

- Linear channel types as protocols.
- Duality of sessions.
- Deadlock-freedom via typing.

## Caveats

- Many dialects (binary vs multiparty).
- Industrial adoption still niche outside research langs.
