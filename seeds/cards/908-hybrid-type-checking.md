# Hybrid Type Checking

## One-sentence takeaway

Hybrid type checking discharges what it can statically and inserts casts for the residual.

## Why it matters here

Bridge between refinement/dependent specs and gradual dynamic checks.

## Key ideas

- Undecidable checking with dynamic residue.
- Cast insertion for leftover obligations.
- Unifies soft/gradual ideas for refinements.

## Caveats

- Part of the gradual/refinement type-safety shelf.
- Check mechanization status in follow-ons.
