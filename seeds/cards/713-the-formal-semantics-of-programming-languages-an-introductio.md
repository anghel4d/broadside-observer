# The Formal Semantics of Programming Languages: An Introduction

## One-sentence takeaway

IMP is given matching operational, denotational, and Hoare-style meanings so a first course can prove the three views agree.

## Why it matters here

When Broadside or the engine needs to write down what a command language *is* — GRID COMMAND, an agent script, a shader IR — Winskel is the course-shaped path from Plotkin SOS and Scott–Strachey domains to a small language you can actually prove things about.

## Key ideas

- A while-language (IMP) is the running example for big-step and small-step operational semantics.
- Domain theory is introduced only as far as needed to interpret recursion and to prove denotational/operational adequacy.
- Hoare logic is developed against the same IMP, so axiomatic reasoning is another view of the same meaning, not a separate subject.
- Later chapters reach higher-order and parallel languages without abandoning the three-style comparison.
