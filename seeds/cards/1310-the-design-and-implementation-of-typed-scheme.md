# The Design and Implementation of Typed Scheme

## One-sentence takeaway

Typed Scheme (Typed Racket) delivers sound migratory typing for an existing untyped language.

## Why it matters here

Canonical migratory typing system; template for migrating dynamic codebases toward types.

## Key ideas

- Occurrence typing for predicates.
- Typed–untyped boundaries via contracts.
- Migratory typing as software engineering.
