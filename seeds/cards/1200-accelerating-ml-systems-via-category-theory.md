# Accelerating Machine Learning Systems via Category Theory: Applications to Spherical Attention for Gene Regulatory Networks

## One-sentence takeaway

Category-theory tools applied to ML systems, with spherical attention for gene-regulatory networks as the worked application.

## Why it matters here

Abbott-lab systems paper sitting between NCDs and the 2026 weaves framework — same algebra, different domain (spherical / GRN).

## Key ideas

- AGI 2025 proceedings Part I, pp. 1–11; DOI `10.1007/978-3-032-00686-8_1`.
- Treats architecture acceleration as a categorical construction, not a one-off kernel.
- Spherical attention as a non-grid geometry that still has to broadcast.

## Caveats

- Short conference paper; GRN application is illustrative. Algebra is developed more fully in Weaves 2026.
