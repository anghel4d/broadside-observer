# Halo / Myth combat-AI sources

GDC 2002 Butcher & Griesemer, *The Illusion of Intelligence / The Integration of AI and Level Design in Halo*.

There is no separate prose paper. The GDC 2002 proceedings entry is the PowerPoint plus speaker notes. HBO converted it to HTML on 2002-04-15.

- `PROCEEDINGS.md` — full speaker notes, slides 1–27 (scraped from HBO)
- `slides/p1.jpg`–`p27.jpg` — HBO slide images
- `slides.pdf` — cleaner PDF of the same deck
- `TRANSCRIPT.md` — earlier compact reconstruction (superseded by PROCEEDINGS.md)

HTML original: http://halo.bungie.org/misc/gdc.2002.haloai/talk.html
